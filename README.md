# CGC Knowledge AI

> **An AI-powered internal knowledge assistant for enterprise document retrieval using Retrieval-Augmented Generation (RAG).**

CGC Knowledge AI is a production-ready web application that enables employees to search, browse, and chat with internal company knowledge using natural language. The platform ingests company documents, automatically extracts and chunks their content, generates semantic embeddings, indexes them in a vector database, and uses a local Large Language Model (LLM) to generate grounded answers with source citations.

The system was developed to reduce the time employees spend searching for internal documentation while minimizing repetitive IT and HR support requests.

---

# Business Goal

Organizations often store policies, procedures, and technical documentation across multiple files, making information difficult to locate quickly.

CGC Knowledge AI addresses this problem by providing employees with a centralized AI assistant capable of answering questions directly from company documentation while citing the original sources.

The platform supports:

- HR policies
- IT documentation
- Security procedures
- Engineering documentation
- Internal knowledge

# System Architecture

```text
                 +---------------------+
                 |    Next.js Client   |
                 +----------+----------+
                            |
                            |
                     JWT REST API
                            |
                            v
                 +----------------------+
                 |      FastAPI API     |
                 +----------+-----------+
                            |
          +-----------------+----------------+
          |                 |                |
          |                 |                |
          v                 v                v
     MongoDB           Qdrant          Ollama LLM
 (documents/users)  (vector search)   (answer generation)
```

MongoDB is the authoritative source for users, documents, metadata, chunks, and embeddings.

Qdrant stores semantic vectors for fast similarity search.

Ollama generates grounded answers using retrieved document context.

```text
        ▼

        │

        ▼

        │
        ▼

        │
        ▼
Hybrid Retrieval
(Keyword + Semantic)
        │
        ▼
Context Ranking
        │
        ▼
LLM Prompt
        │
        ▼
Grounded Answer + Citations
```

# Local Installation

## Backend

```powershell
cd backend

python -m venv venv

.\venv\Scripts\Activate.ps1

pip install -r requirements.txt

Copy-Item .env.example .env

uvicorn app.main:app --reload
```

## Frontend

```powershell
cd frontend

npm ci

Copy-Item .env.example .env.local

npm run dev
```

# Known Limitations

- JWTs are currently stored in browser storage.
- Refresh tokens are not implemented.
- Password reset functionality is not available.
- Chat history is stored locally.
- Maintenance history exists only for the current browser session.
- Ollama must be running locally.
- AI response time depends on local hardware performance.

# Production Checklist

- Configure a secure JWT secret.
- Configure production CORS origins.
- Remove bootstrap credentials after deployment.
- Ensure MongoDB and Qdrant use persistent storage.
- Verify Ollama models are installed.
- Confirm `/health` and `/ready` return successful responses.
- Complete embedding and vector backfills.
- Run backend tests and frontend production build.
- Verify role permissions and document ingestion.
- Configure HTTPS, backups, monitoring, and logging.
